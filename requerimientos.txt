Tu tarea es ayudarme a desarrollar un proyecto de escritorio llamado "PhotoDroid", una herramienta de análisis, diagnóstico y limpieza controlada de dispositivos Android conectados mediante USB.

Para la interfaz web (Frontend), utilizaremos **HeroUI (heroui.com)** junto con **Tailwind CSS** para lograr un diseño moderno, profesional, limpio y con componentes visuales de alta calidad (tarjetas, botones, tablas, barras de progreso y modales), con un estilo tipo dashboard de ciberseguridad.

A continuación, te detallo la arquitectura, tecnologías y módulos que componen el sistema para que los tengas como referencia en todo momento:

1. ARQUITECTURA Y COMUNICACIÓN
- El proyecto utiliza PySide6 con QWebEngineView para renderizar la interfaz web (construida con HeroUI/Tailwind/JS) dentro de una ventana de escritorio de estilo moderno.
- La comunicación bidireccional entre JavaScript y Python se realiza mediante `QWebChannel`. Un objeto expuesto desde Python (backend) permite que JS ejecute funciones del sistema y que Python envíe actualizaciones en tiempo real (mediante Signals/Slots de Qt).
- Toda la pesada lógica de análisis de seguridad y comandos ADB se ejecuta en Python en hilos separados (QThread) para evitar congelar la interfaz.

2. TECNOLOGÍAS
- Backend: Python, PySide6, subprocess (para ADB).
- Frontend: HTML5, Tailwind CSS, HeroUI (https://heroui.com), JavaScript.
- Puente: QWebChannel, QWebEngineView.
- Comunicación con dispositivos: ADB (Android Debug Bridge).
